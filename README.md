# SEO-центр (навыки opencode + визуальный UI)

Перенос SEO-центра между машинами. В архиве: навыки opencode, плагин визуального UI (порт 4180), конфиги и вспомогательные скрипты.

## Быстрый перенос (навык `seo-center-backup`)

Сохранение всего SEO-центра в один версионный архив:

```bash
bash .opencode/skills/seo-center-backup/scripts/backup.sh
```

или скажи в opencode: **«сохрани seo центр»** (есть и команда `/seo-backup`).
Архив появится в `seo-center-archives/seo-center-<хост>-<дата>.tar.gz.enc`
(зашифрован AES-256; плюс симлинк `latest.tar.gz.enc`). В него входят проект,
навыки, плагин, глобальные настройки opencode, auth-ключи, OmniRoute и
systemd-сервисы, но он защищён парольной фразой из
`~/.config/opencode/seo-backup-pass`.

Установка на другом ПК:

```bash
bash .opencode/skills/seo-center-backup/scripts/restore.sh seo-center-*.tar.gz.enc
```

или распакуй архив в папку проекта, открой её в opencode и скажи
**«распакуй seo центр»** (команда `/seo-restore`). Установщик сам поправит
пути, поставит зависимости и включит сервисы.
Прежняя версия сохраняется в `~/seo-center-backups/pre-restore-<дата>/`.

> Архив содержит ключи доступа — храни и передавай только по защищённым каналам.

## Состав архива

```
.
├── opencode.json                  # конфиг проекта (MCP playwright)
├── package.json                   # зависимости проекта (playwright для Wordstat)
├── package-lock.json
└── .opencode/
    ├── package.json               # зависимость плагина (@opencode-ai/plugin)
    ├── plugin/
    │   ├── seo-ui.ts              # плагин — веб-интерфейс «SEO-инструменты» (http://localhost:4180)
    │   └── bg.png                 # фоновое изображение UI
    └── skills/
        ├── adresa-stranits/       # навык: аудит адресов страниц (Текарт → .docx)
        ├── seo-articles/          # навык: SEO-статьи
        ├── seo-metatags/          # навык: метатеги по семядру
        ├── seo-metatags-extract/  # навык: выгрузка метатегов с сайта
        ├── seo-topics/            # навык: темы для статей
        ├── smm-groups/            # навык: анализ групп ВК/Telegram/MAX → XLSX
        └── wordstat/              # навык: сбор данных Wordstat
            ├── SKILL.md
            ├── wordstat-api.js    # сбор через JSON API Wordstat (Playwright)
            └── test-queries.tsv   # пример списка запросов
```

## Требования

- **opencode** (десктопное приложение или CLI) — версия, поддерживающая плагины.
- **Node.js** (18+).
- Для навыка `wordstat`: `npm i playwright` + `npx playwright install chromium`.
- Для плагина: `npm i` в папке проекта (установит `@opencode-ai/plugin`).

## Развёртывание на новой машине

1. **Распакуй архив** в папку будущего проекта, например:
   ```
   C:\Users\<ты>\Desktop\open code\
   ```

2. **Установи зависимости** в корне проекта:
   ```
   npm install
   ```
   (в корне — playwright; в `.opencode` — зависимость плагина)

3. **Установи браузер Playwright** (для Wordstat):
   ```
   npx playwright install chromium
   ```

4. **Открой папку в opencode** (десктопное приложение: «Открыть проект» → папка проекта).

5. Плагин поднимется автоматически — в консоли появится адрес:
   ```
   http://localhost:4180
   ```
   Открой его в браузере — это визуальный «SEO-центр» (вкладки «SEO-инструменты», «SEO-аудит» и «SMM-инструменты»: выгрузка метатегов, метатеги по семядру, Wordstat, темы статей, статьи, аудит, анализ групп соцсетей, результаты).

   **Стабильный адрес для коллег:** панель всегда слушает фиксированный порт **4180** (`0.0.0.0`), поэтому в локальной сети она доступна по `http://<IP-машины>:4180/` — например `http://192.168.0.121:4180/`. Порт можно переопределить переменной `SEO_UI_PORT`. Если на порту уже работает другая копия SEO-панели (второй opencode), плагин переиспользует её, а не поднимает новый сервер; если порт занят посторонним сервисом — предупредит в консоли и возьмёт следующий свободный.

## Настройка Wordstat (авторизация Яндекса)

Профиль браузера Playwright с авторизацией в Яндекс **не входит** в архив (персональные данные).

При первом использовании Wordstat выполни вход:
```
node .opencode\skills\wordstat\wordstat-api.js <файл.tsv> --renew
```
— откроется окно браузера, войди в Яндекс; сессия сохранится в папке `pw-profile` внутри навыка.

## Проверка после развёртывания

1. Открой `http://localhost:4180` — должна открыться страница «SEO-центр» с вкладками.
2. Вкладка «Выгрузка метатегов»: введи URL сайта, нажми «Запустить выгрузку».
3. В терминале opencode должен запуститься навык `seo-metatags-extract`, результат появится в папке `seo-results/<сайт>_<дата>/`.

## Защита от копирования и утечек

Слой защиты от копирования алгоритмов и настроек:

- **Пароль панели** (как и раньше) — `~/.config/opencode/seo-center-auth.json`.
- **Allowlist по IP** — `SEO_UI_ALLOW_IPS="192.168.0.*"` (через запятую: точный IP,
  `192.168.0.*` или CIDR `192.168.0.0/24`). Пусто — доступ всем.
- **Только локально** — `SEO_UI_BIND=127.0.0.1` слушать лишь localhost.
- **Журнал аудита** — кто и когда запускал задачи: `~/.config/opencode/seo-center-audit.log`.
- **Анти-брутфорс** — блокировка IP после 10 неудачных входов за 10 минут.
- **Заголовки безопасности** — noindex, X-Frame-Options: DENY, CSP и др.
- **Шифрование архивов** — бэкапы сохраняются как `.tar.gz.enc` (AES-256).
- **Разделение секретов** — `--no-secrets` собирает архив без ключей, сессий и
  бренд-контекста; права на секреты — `600`, на папки — `700`.

Алгоритмы (`SKILL.md`) — обычные текстовые промпты на диске, которые opencode
читает в рантайме, поэтому «спрятать» их технически нельзя: защита сводится к
тому, чтобы не давать доступ к файлам и архивам.

## Примечания

- Результаты всех запусков складываются в `seo-results/<сайт>_<дата>_<время>/` внутри папки проекта.
- Вкладка «Результаты» и «Результаты аудита» показывают эти файлы (с фильтром по году/месяцу) и позволяют скачать/удалить их.
- SEO-панель закреплена на порту **4180** (стабильный URL для коллег). Если порт занят нашей же копией — переиспользуем её; если посторонним сервисом — берём следующий свободный и предупреждаем в консоли. Переопределить порт: переменная `SEO_UI_PORT`.
