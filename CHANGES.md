## 27. Запуск проекта: критический фикс загрузки панели

Панель не запускалась вовсе — `seo-ui.ts` не загружался ни Node 26, ни esbuild
(`ERR_INVALID_TYPESCRIPT_SYNTAX`, «import/export outside module code»). Причина —
потерянные закрывающие скобки `}`: у `enqueueAudit` (после `return result2` в
очереди аудитов) и, как следствие, сдвиг скоупов до конца файла.

- Восстановлены обе `}` — файл снова валидный, панель стартует.
- Найден и исправлен скрытый баг `enqueueAudit`: функция работала с голой
  переменной `site` (которой нет в скоупе) вместо `args.site` — «Повторить»,
  планировщик и dry-run возвращали «URL не указан». Добавлена `const { site } = args`.
- dry-run аудит теперь не упирается в запрет «сайт уже в очереди» и не запускает
  задачу реально (остаётся в очереди, историю не пишет).
- Тест dry-run приведён в соответствие: проверяет «ничего не добавлено в историю»,
  а не «история пуста».

Итог: 48/48 тестов проходят (ранее панельный набор вообще не выполнялся).

## 1. «Повторить» и планировщик не теряют параметры (план п.1)

До этого момента кнопка «Повторить» и расписание брали из истории только список
пунктов — глубины 2.1/4.1 и приложенное семантическое ядро терялись, повтор
уходил с дефолтами 50/10 и без семядра.

- `RunRecord` и `Schedule` получили поля `depthContent`, `depthSpeed`,
  `semcoreMsg`, `semcorePath`.
- «Повторить» берёт глубины и семядро из последнего прогона сайта.
- Планировщик берёт глубины из расписания; если не заданы — из последнего прогона.
- В UI добавлены поля глубины при создании расписания.
- Все пути запуска (форма, повтор, планировщик) используют один и тот же код
  (`enqueueAudit` / `buildAuditPrompts`) — результаты не расходятся.

## 2. Ложные дубли title/description убраны через каноник (план п.2, высокая критичность)

На qegg.ru «дубль title» показывал 390 страниц, но среди них масса пагинаций
(`?PAGEN_1=2`), слэш/без слэша, фильтров — это законные шаблоны, а не ошибка.

- `meta_audit.py` нормализует URL (убирает trailing slash, `?PAGEN_1=N` и т.п.)
  для группировки дублей.
- Извлекает `rel=canonical` со страницы. Страница не считается проблемным
  дублем, если на неё стоит canonical на другую страницу группы (пагинация,
  слэши, фильтры). Реальные дубли остаются, ложные — убираются из скора.
- Пороги длины приведены к правилам проекта: **title 50–100, description 170–250**
  (было 30–70 / 70–200).
