# Навык: внешний аудит конкурентов (off-site)

Выходит **за рамки сайтов** и собирает внешнее присутствие конкурентов: соцсети,
упоминания в интернете, каталоги и справочники, реестры и тендеры, площадки
отзывов, тональность отзывов — и **дополняет таблицу-аудит конкурентов**
(Google Sheets) в строках, посвящённых внешнему маркетингу.

> **Важно:** навык самодостаточен и **не связан** с `audit-konkurentov`
> (тот делает записку-.docx по готовой таблице). Не вызывай их друг из друга и
> не ссылайся одним на другой. Это два независимых навыка.

## Когда использовать

Пользователь даёт:
- ссылку на таблицу-аудит конкурентов (Google Sheets) и **название вкладки**
  (направление, например «Покраска металлоизделий»);
- список компаний-конкурентов (это столбцы таблицы; первая колонка — обычно
  заказчик, далее конкуренты);
- (опц.) уже заполненные строки — трогать их нельзя, см. ниже.

## Что заполняем и что НЕ трогаем

Заполняем **только** эти строки (находим их по названию в колонке A; номера
строк могут отличаться от примера — ориентируйся на подпись, не на номер):

| Подпись в колонке A | Что пишем |
| --- | --- |
| Работа с социальными сетями | соцсети с URL, подписчиками, датой/частотой постов, типом контента |
| Комментарий | краткое резюме по соцсетям (ведутся/заброшены, кросспостинг) |
| Ресурсы (примеры) | внешние каталоги/справочники/СМИ/реестры со ссылками |
| Типы упоминания/размещений | карточки организации/услуг, отзывы, PR, форумы, реквизиты, тендеры |
| Площадки (примеры) | площадки отзывов с рейтингом и числом отзывов |
| Тональность | что хвалят / на что жалуются |
| Выводы | только про соцсети, PR-активность и работу с отзывами |

**Ничего вне этого списка не менять.** Если пользователь уже редактировал
другие (более высокие) строки — их не перезаписывать. При сомнении — уточнить.

## Порядок работы

> Для длинных задач выводи маркеры `[[stage:N/M]]`.

### 1. Считать таблицу
Открой таблицу (Google Sheets), активируй нужную вкладку, выпиши по колонке A
названия строк и по строке 1 (или строке с названиями) — список компаний.
Для каждой компании возьми её сайт из строки «Сайт компании».

### 2. Соцсети (по реальным ссылкам)
- Собери ссылки на соцсети **с самого сайта** (шапка/футер/контакты).
- Также поищи официальные профили по бренду (ВКонтакте, Telegram, YouTube,
  RuTube, Дзен, Одноклассники, MAX, Pinterest, TikTok).
- По **каждой** ссылке открой страницу и зафиксируй: число подписчиков,
  дату/частоту последних публикаций, тип контента (фото/видео/текст),
  активность и (если видно) вовлечённость (лайки/репосты), наличие кросспостинга.
- Отмечай заброшенные каналы (последний пост год+ назад) и битые ссылки
  (иконки соцсетей, ведущие на «/»).

### 3. Упоминания в интернете и каталоги
Ищи карточки и упоминания вне сайта:
- справочники/карты: Яндекс.Карты/Яндекс.Бизнес, 2ГИС, Zoon, Flamp, Yell,
  Пласо (plaso.pro), XTOOL, Avito, Яндекс.Услуги, местные каталоги;
- отраслевые каталоги и тематические ресурсы;
- реестры/проверка контрагента (rusprofile, checko, list-org, audit-it,
  b2b.house, RBC Companies, Контур.Фокус) — по ИНН/названию;
- тендеры/госзакупки (rutend, tenderguru, b2book, zakupki.kontur.ru);
- СМИ/PR-публикации и новости;
- форумы (автоклубы, отраслевые) и соцсети, где упоминают компанию.

### 4. Площадки отзывов
Проверь площадки с отзывами и для каждой найденной укажи: **ссылку, рейтинг,
число отзывов/оценок**:
Яндекс.Карты, 2ГИС, Zoon, Flamp, Otzovik, IRecommend, Google Maps, Пласо,
отраслевые. Если отзывов на площадке нет — так и пиши.

### 5. Тональность
Кратко: что хвалят, на что жалуются; где преобладает позитив, где есть резкий
негатив. Учитывай давность отзывов.

### 6. Запись в Google Sheets
Внеси данные **только в перечисленные строки**. Техника — в разделе ниже.
После вставки проверь 2–3 ячейки (формула-бар) и убедись, что строки выше не
изменились.

## Правила

- **Реальные данные**, открывай каждую ссылку; **всегда указывай URL**.
- Ничего не выдумывать; нет данных — писать «Не обнаружено».
- Не путать одноимённые компании (проверяй адрес/город/профиль).
- Всегда открывай **новую** вкладку браузера, не трогай вкладки пользователя.
- Пиши сжато, по образцу существующих заполненных строк таблицы.
- В ячейке можно использовать переносы строк — перечисляй пункты с новой строки.

## Техника: браузер с авторизацией пользователя

Многие сервисы (правки в Google Sheets, pr-cy, соцсети, каталоги) требуют
авторизации. Используй **профиль пользователя Chrome**: подними отдельный
Chrome под виртуальным дисплеем (Xvfb) с копией профиля и портом отладки, затем
подключайся по CDP.

```bash
scripts/browser-session.sh 9222      # поднимет Xvfb :99 + Chrome с портом 9222
```

Остановка (в конце работы): закрыть процесс Chrome на этом порту и `Xvfb :99`.
Не оставляй временный Chrome/Xvfb запущенными.

## Техника: вставка блоков в Google Sheets

Google Sheets принимает вставку HTML-таблицы в выбранную ячейку (диапазон).
Многострочные ячейки сохраняются как переносы строк внутри ячейки.

1. Собери для каждой группы строк **HTML-таблицу** (столбцы — компании,
   строки — пункты). Проще всего из JSON через хелпер:
   ```bash
   node scripts/make-block.mjs templates/example-block.json /tmp/blk_38.html
   ```
   (`<td>` — ячейка; перенос строки внутри текста = `\n` в JSON → `<br>`).
2. Вставь блоки скриптом (одна вкладка листа, несколько блоков по указанным
   ячейкам):
   ```bash
   node scripts/paste-blocks.mjs \
     --cdp http://127.0.0.1:9222 \
     --sheet "https://docs.google.com/spreadsheets/d/<ID>/edit" \
     --tab "Покраска металлоизделий" \
     --block "B38:/tmp/blk_38.html" \
     --block "B41:/tmp/blk_41.html"
   ```
   Скрипт: активирует вкладку, для каждого блока копирует HTML-страницу и
   вставляет её в ячейку (через поле «Имя ячейки» `#t-name-box`), затем
   проверяет результат через формула-бар (`#t-formula-bar-input`).
3. Первая ячейка блока — это ячейка **первого столбца данных**
   (обычно `B<row>`, если в колонке A — подписи строк).
4. Чтобы не задеть строки-разделители, вставляй **непрерывными группами**
   (например, B38 и B39 отдельным блоком, B41–B42 отдельным и т.д.).

### Если файл — загруженный .xlsx и открывается в Google Таблицах
Правки возможны напрямую в интерфейсе Google Sheets (как в обычной таблице).

## Состав навыка

- `SKILL.md` — этот файл.
- `scripts/browser-session.sh` — поднять Chrome с профилем пользователя под
  Xvfb и CDP-портом (`9222`). Linux; для macOS/Windows путь профиля другой.
- `scripts/make-block.mjs` — JSON → HTML-таблица для вставки.
- `scripts/paste-blocks.mjs` — вставка HTML-блоков в Google Sheets по CDP.
- `templates/example-block.json` — пример структуры блока.
- `package.json` — зависимость `playwright` (для `paste-blocks.mjs`).
