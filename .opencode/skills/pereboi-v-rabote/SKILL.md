# Технический аудит сайта (методология «Текарт»)

## Результаты пункта 4.2
**`Перебои в работе сайта.docx`**:
- подводка (почему важна доступность сайта);
- **ссылка на итоговый тест** (вида `https://ping-admin.com/free_test/result/<id>.html` или
  `https://check-host.net/check-report/<id>`);
- количество точек, успешных/неуспешных, среднее время;
- **вывод**: «проблем не обнаружено — исправления не требуются» ИЛИ перечень проблем и как исправить.

## Порядок работы

> **Отчёты о ходе (для прогресс-бара).** Выведи `[[stage:1/3]]` в начале, `[[stage:2/3]]` перед
> анализом результатов и `[[stage:3/3]]` перед сохранением файла.

1. **Запустить бесплатную проверку на `https://ping-admin.com/free_test/`** — только точки РФ
   (чекбоксы `ru*`), дождаться результата.
2. **Если сервис вернул результат без данных по точкам** (у Ping-Admin бывает для анонимных запросов) —
   **фолбэк**: проверить сайт с российских узлов через **`check-host.net`** (бесплатный API) и
   использовать его отчёт. Ссылку Ping-Admin при этом всё равно указываем в документе.
3. **Проанализировать**: сколько точек ответили, есть ли недоступные/медленные (> 5 c).
4. **Вывод**:
   - если все точки ответили и нет медленных — «проблем не обнаружено, исправления не требуются»;
   - если есть недоступные/медленные — перечислить и дать рекомендации (хостинг, ресурсы сервера,
     кэш/CDN, DNS/SSL, мониторинг доступности).

## Структура .docx
- Обложка; `Heading 1` — «Анализ технических факторов со стороны сервера», `Heading 2` — «4.2. Перебои в работе сайта».
- Подводка → ссылка на тест (и источник данных) → результаты по точкам РФ → вывод → (при проблемах) таблица проблемных точек и рекомендации.

## Техника
Скрипт: `scripts/uptime_audit.py`
```bash
python3 scripts/uptime_audit.py --url https://<host>/ --out-dir <папка> [--timeout 240]
```
Зависимости: `pip3 install --break-system-packages requests beautifulsoup4 python-docx`.

## Что НЕ относится к пункту 4.2
- Скорость загрузки страниц — пункт 4.1.
- Технические/серверные факторы в целом — другие пункты раздела 4.
