# Технический аудит сайта (методология «Текарт»)

## Важно про источник данных
Полный профиль входящих ссылок **без доступа к Яндекс.Вебмастеру / Google Search Console / платному API
получить нельзя** (поисковики и бесплатные чекеры блокируют автоматику). Скрипт собирает то, что можно
получить своими силами: **доноров из собственного каталога/обменных страниц сайта и проверяет взаимность**
(реально ли донор ссылается обратно). Об этом прямо сказано в документе. Если позже появится Вебмастер или
экспорт — передайте файл через `--backlinks`, и скилл проанализирует полноценный профиль.

## Результаты пункта 3.2
1. **`Внешние ссылки.docx`** — подводка, источник данных, проблемы (объём, ресурсы, качество, мусор),
   таблица доноров и оценка, рекомендации (чистка + белые методы наращивания).
2. Лист **«Внешние ссылки»** в общей `Контент_<хост>.xlsx`:
   `№, Домен-донор, Ссылается обратно, TLD, Тематический, Внешних ссылок на доноре, rel, Анкор, Оценка, Класс, Комментарий`.

## Порядок работы

> **Отчёты о ходе (для прогресс-бара).** Выведи `[[stage:1/3]]` в начале, `[[stage:2/3]]` перед
> оценкой доноров и `[[stage:3/3]]` перед сохранением файлов.

1. **Собрать доноров** своими силами: обойти сайт, найти страницы с плотной внешней перелинковкой
   (каталог ссылок, обменные страницы), выписать домены-кандидаты.
   (Если есть `--backlinks` — взять доноров из файла.)
2. **Проверить взаимность** по каждому донору: загрузить его главную и типовые страницы ссылок,
   найти ссылку на сайт, определить `rel` (dofollow/nofollow) и число исходящих ссылок донора.
3. **Оценить качество**: тематическая релевантность, TLD, спам-признаки в домене, размер ссылочного
   вывода (ссылочная ферма), подтверждённость обратной ссылки. Класс: Хорошая / Средняя / Мусорная.
4. **Сформировать** `.docx` и лист XLSX.

## Что писать в документе
- **Подводка** — зачем важны входящие ссылки и их качество.
- **Источник данных** — честно: свой сбор (не полный профиль) / Вебмастер / экспорт.
- **Проблемы** — объём (сколько доноров), какие ресурсы, качество (хорошие/средние/мусор), профиль
  (обмен/каталоги vs естественные упоминания).
- **Рекомендации**:
  - чистка: мусорные/нерелевантные — снять или в disavow (GSC) / отклонить (Яндекс); отказ от обмена ссылками;
  - рост белыми методами: экспертный контент, гостевые статьи в отраслевых СМИ, отраслевые каталоги/ассоциации,
    PR и новости, партнёрские программы, Яндекс.Бизнес/2ГИС/Google Business, соцсети, digital-PR, естественные упоминания;
  - мониторинг: Вебмастер/GSC/алерты.

## Техника
Скрипт: `scripts/backlink_audit.py`
```bash
python3 scripts/backlink_audit.py --url https://<host>/ --out-dir <папка> [--backlinks <файл>] [--no-verify] [--max-donors 50]
```
Зависимости: `pip3 install --break-system-packages requests beautifulsoup4 openpyxl python-docx`.
