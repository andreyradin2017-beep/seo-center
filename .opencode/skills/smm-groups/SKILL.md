# Навык: анализ групп в соцсетях (SMM)

Собираем статистику по **опубликованным постам** в группах/каналах за заданный период
и формируем таблицу `.xlsx`. Поддерживаются площадки: **ВКонтакте**, **Telegram**, **MAX**.
Группы можно указывать вперемешку — навык сам определяет площадку по ссылке.

## Входные данные (приходят из плагина)

- **Группы/каналы** — список ссылок (по одной на строку).
- **Период** — `с YYYY-MM-DD по YYYY-MM-DD` включительно.
- **Аккаунт для входа** (необязательно) — телефон/логин.
- **Папка результата (`outDir`)** — единственное место, куда сохраняем файлы.

## Отчёты о ходе (для прогресс-бара)

При запуске из плагина выводи маркеры этапов:
`[[stage:1/4]]` — подготовка и определение площадок; `[[stage:2/4]]` — сбор постов;
`[[stage:3/4]]` — сбор статистики; `[[stage:4/4]]` — формирование XLSX.

## Поля отчёта (порядок колонок фиксирован)

| Ключ | Колонка |
| --- | --- |
| `post_url` | Ссылка на пост |
| `published_at` | Дата публикации |
| `likes` | Лайки |
| `reposts` | Репосты |
| `votes` | Голоса |
| `comments` | Комментарии |
| `views_total` | Просмотры всего |
| `hashtags` | Хештег поста |
| `text` | Текст поста (без хештега) |

Если площадка не отдаёт часть полей — **колонка остаётся, значение пустое**.
Посты и группы не пропускаем: даже при отсутствии статистики пост попадает в таблицу.

### Доступность метрик по площадкам

| Поле | ВКонтакте | Telegram | MAX |
| --- | --- | --- | --- |
| Ссылка, дата, текст, хештеги | да | да | частично |
| Лайки / репосты | да | — | — |
| Голоса (реакции) | да (опросы/реакции) | да (реакции) | — |
| Комментарии | да | да (если видны) | — |
| Просмотры всего | да | да | частично |

> Охват/переходы/подписки ВКонтакте (переходы по ссылкам, отписавшиеся/подписавшиеся,
> просмотры подписчиков и не подписчиков) доступны **только владельцу/администратору**,
> поэтому в отчёт не включаются.

## Порядок работы

> **[[stage:1/4]]** Разбери вход: список групп, период, `outDir`. Определи площадку
> каждой ссылки (`vk.com`/`vk.ru` → ВК, `t.me`/`telegram.me` → Telegram,
> `max.ru`/`max.mail.ru` → MAX). Проверь зависимости (см. ниже).

### 1. Зависимости

```bash
# из корня проекта
npm i playwright
npx playwright install chromium
# для сборки XLSX
pip3 install --break-system-packages openpyxl
```

Профиль авторизации хранится в `.opencode/skills/smm-groups/pw-profile` и
переиспользуется между запусками. Для входа в закрытые группы/полную статистику
запусти сборщик один раз с флагом `--headed`, войди в окне — сессия сохранится.

> **[[stage:2/4]] [[stage:3/4]]** Запусти сборщик (он сам проходит по ленте за период,
> собирает метрики и на [[stage:4/4]] формирует XLSX):

```bash
node .opencode/skills/smm-groups/scripts/collect.js \
  --groups "СПИСОК_ГРУПП_ЧЕРЕЗ_ЗАПЯТУЮ" \
  --from YYYY-MM-DD --to YYYY-MM-DD \
  --out "ПУТЬ_К_outDir" \
  --project "ИМЯ_ПРОЕКТА" \
  [--account "ТЕЛЕФОН_ИЛИ_ЛОГИН"] [--headed]
```

Полезные ключи: `--groups-file file.txt` (список из файла), `--headed` (видимый
браузер для входа/отладки), `--max-scrolls N`, переменные `SMM_HEADLESS=0|1`,
`SMM_MAX_SCROLLS=N`. Скрипт сам вызывает `build_xlsx.py`.

Если Playwright недоступен или площадка не поддаётся автоматизации — собери данные
вручную (Playwright MCP) и сформируй таблицу из подготовленного JSON-массива строк
(ключи — из `fields.json`, см. ниже):

```bash
python3 .opencode/skills/smm-groups/scripts/build_xlsx.py \
  --rows "$outDir/smm_rows.json" \
  --fields .opencode/skills/smm-groups/scripts/fields.json \
  --out "$outDir/SMM_группы_<проект>.xlsx"
```

`build_xlsx.py` создаёт два листа: **«Посты»** (строка = пост) и **«Сводка»**
(по группам: количество постов и суммы метрик).

### 2. Как собираются посты по площадкам

- **ВКонтакте** (`collect-vk.js`): открываем стену группы, разворачиваем ленту
  прокруткой, берём посты с датой в периоде. Публичные счётчики — лайки, репосты,
  комментарии, просмотры (в т.ч. голоса опросов). Метрики охвата и переходы
  (переходы по ссылкам, отписки/подписки, разбивка просмотров на подписчиков/не
  подписчиков) доступны только администратору и в отчёт не включаются.
- **Telegram** (`collect-tg.js`): публичный предпросмотр `https://t.me/s/<channel>`
  (без входа). Просмотры и сумма реакций (голоса), число комментариев, дата, текст,
  хештеги. Пагинация назад через `?before=<id>`. Закрытые каналы не поддерживаются
  без входа.
- **MAX** (`collect-max.js`): веб-версия MAX отдаёт минимум — собираем ссылку, дату,
  текст и хештеги; остальные поля пустые. Если посты не распознаны, группа всё равно
  отмечается в сводке (0 постов) с предупреждением.

## Правила

- Сохраняй **все** файлы (XLSX, `smm_rows.json`, при необходимости промежуточные)
  **только в `outDir`**, переданный в задании. В других местах файлы не создавай.
- Имя итогового файла: `SMM_группы_<проект>.xlsx` (проект = ключ из `outDir`).
- Для длинных лент не устраивай слишком агрессивный скроллинг — держи паузы из
  `config.json`, чтобы площадка не показала капчу.
- Сессия в `pw-profile/` содержит cookies — не коммить её в git.
- В ответ выведи: путь к XLSX, сколько групп и постов собрано, какие поля недоступны.
